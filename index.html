FixMyCity

An Android app for reporting problems in the city. A resident takes a photo of the problem and registers a complaint, which raises a ticket for the municipal corporation. An admin assigns the work to a worker, and the worker reports the details of the job back to the admin.

3roles: citizen, admin, worker
Photoattached to every complaint
Ticketraised for each report

  • Citizen

    Registers a complaint by adding a photo of the problem. Submitting it raises a ticket that goes to the municipal corporation.

  • Admin

    Receives the tickets and assigns the work to a worker.

  • Worker

    Carries out the assigned work and sends the details of it back to the admin.

  • Android
  • Java
  • XML

Task Manager

Create a task, mark it complete, delete it, and filter the list to all, completed or to-do. Pages are rendered on the server with EJS, while completing and deleting run through fetch calls, so the list updates in place without a reload.

5Express routes
3list filters
MVCproject layout

  • Layered structure

    The Mongoose model, the Express router and the controller functions each live in their own folder. The entry point only sets up middleware, connects to MongoDB and mounts the routes.

  • PUT and DELETE from the browser

    Completing and deleting are PUT and DELETE endpoints that answer in JSON. The page calls them with fetch and updates the card when the request succeeds, fading a deleted task out rather than reloading.

  • Views

    ejs-mate layouts give every page one shared boilerplate with header and footer partials. Bootstrap styles the cards and the new-task form.

  • Node.js
  • Express.js
  • MongoDB
  • Mongoose
  • EJS
  • Bootstrap
